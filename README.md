### ⚡ Overview

CanvasCraft is a responsive, web-based drawing workstation engineered with native browser APIs. It brings desktop-grade painting tools directly into the browser without heavy frontend libraries or external packages.

---

### ✨ Feature Highlights

| Tool Category | Available Capabilities |
| :--- | :--- |
| **Geometry Engine** | Draw dynamic shapes on the fly including **Rectangles**, **Circles**, and **Triangles** with one-click **Fill Color** toggling. |
| **Brush Controls** | Precision freehand brush paired with a clean **Eraser mode** and an interactive **Stroke Width Slider** for variable line thickness. |
| **Color Studio** | One-touch quick palette shortcuts alongside a full-spectrum **Native System Color Picker** for precise hex/RGB tuning. |
| **Canvas Operations** | Wipe the workspace instantly using **Clear Canvas** or export your high-resolution sketch via **Save As Image**. |

---

### 🛠 Tech Stack

1. **HTML5 Canvas API**: Drives the high-performance 2D rendering pipeline and coordinate tracking.
2. **Vanilla JavaScript (ES6+)**: Handles dynamic mouse event listeners, state tracking, and geometry calculations.
3. **CSS3**: Powers the modern floating-card interface with smooth sliders and custom inputs.
